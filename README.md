# studio

A content studio for your videos, built for Runneth. Every video you work on becomes one project with one folder and one card in your studio. Open the card to pick your takes, pick your b-roll and review each edit, all in one place.

Made by [Alysha](https://github.com/alyshadotmd) while building her own AI video editing stack.

> Work in progress. The skill is being written now.

## The skill

| Skill | What it does |
|---|---|
| [`edit-studio`](skills/edit-studio/SKILL.md) | Names each video, makes its project folder, and gives it one card in your content studio with Takes, B-roll and Review edit tabs. |

## How to use it

Add the skill folder to your skills in Runneth. Runneth only for now.

Pairs with the editing skills in [video-editing](https://github.com/alyshadotmd/video-editing).
